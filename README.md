## ✨ Features

- 🎨 **Dark-themed glassmorphism design** with animated particle background
- ⌨️ **Typing animation** in the hero section (powered by Typed.js)
- 🖱️ **Tilt effect** on cards and images (Vanilla Tilt.js)
- 📜 **Scroll reveal animations** for smooth section entrances
- 📱 **Fully responsive** layout for all screen sizes
- 📬 **Working contact form** via FormSubmit
- 🔝 **Scroll-to-top button**
- ⚡ **Animated skill progress bars**
- 🖼️ **Preloader animation** on page load

## 🏁 Getting Started

This is a **static website** — no build tools or dependencies required.

### Option 1 — Open directly
```bash
# Simply open index.html in your browser
start index.html
```

### Option 2 — Serve with VS Code Live Server
1. Install the **Live Server** extension in VS Code
2. Right-click `index.html` → **Open with Live Server**

### Option 3 — Serve with Python
```bash
# Python 3
python -m http.server 8000
# Then visit http://localhost:8000
```
